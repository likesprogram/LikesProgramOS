# Docs — 规格、手册与约定

| 目录 | 内容 |
| --- | --- |
| `Specs/` | 各领域的正式规格：接口、契约、边界与取舍 |
| `Manuals/` | 面向实现者与使用者的手册：按它就能写出可用的实现 |

入口索引见顶层 [README](../README.md#文档索引)。

## 记录

- [缺陷与修复记录](Test/缺陷与修复记录.md)：测试发现的缺陷流水，写清现象、影响、根因、修法与回归网；一条缺陷只有回归网落地才算关闭
- [Baleen 验证报告](Test/Baleen-验证报告.md)：Baleen 子项目的验证标准、用例矩阵、失败注入、UEFI 自建控制器路径与实机排除项，附证据目录与复现命令
- [P5 口径扫描判定清单](Test/P5口径扫描判定清单.md)：M0 收口时对尚未落地的悬空口径与已退役口径的逐条判定记录；复核方式是重跑清单里的扫描命令
- [退役项清单](Test/退役项清单.md)：已退役口径与实现的登记表、现行单点与 grep 允许命中位置；含复核命令与 M7 T7.6 执行记录
- `Test/Evidence/`：历史验证证据目录（不进仓库；旧目录标注为「P5 前基线」）

## 手册

- [镜像制作器与安装器实现手册](Manuals/镜像制作器与安装器实现手册.md)：为 LikesProgramOS 产出可引导介质的实现指南——描述符区格式、需要写回的信息与位置、建议流程，以及通用镜像制作器与测试安装器的定位与能力边界
- [体积与内存报告](Manuals/体积与内存报告.md)：M7 T7.4 的 D10 体积统计、启动峰值与运行期常驻的可观测口径，含复现命令、硬上限对照与未验证项
