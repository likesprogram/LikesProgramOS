# 失败诊断编号

本文登记引导链各阶段的稳定失败编号：`E-IPL`、`E-STUB` 与 `E-CORE`。编号是工单、日志聚合与自动化回归引用的标识；**同一编号的含义一经发布不再改动，文本可以润色**。编号随诊断行一起输出：Stub 与 BaleenCore 的 `FATAL` / `WARN` 行格式为 `[ FATAL ] E-CORE-07 <文本>`，编号与文本之间一个空格。

编号在各阶段内唯一，序号不要求连续。文本与编号的配对定义在源码里的 `Baleen::Diagnostic` 常量（`Packages/Baleen/Common/Include/Diagnostics.hpp`）；本表是它的登记副本，**新增编号必须同时改源码与本文**。回归工具按编号或文本子串断言，改动文本时须同步检查 `CheckStub` / `CheckIpl` 的期望值。

## 一、E-IPL：一级引导

IPL 是 16 位纯汇编，446 / 510 字节的首段预算放不下编号文本：失败码是**大于零的整数**，屏幕上与 `0xE9` 调试口里各输出它的一位十六进制字符（码 `1`..`7` 输出 `1`..`7`）。一位十六进制是本阶段预算下的宽度上限；码值取到 `0xF` 为止，新增码超过它时必须连同输出程序一起改。码值与登记编号同号，含义见[一级引导契约](一级引导契约.md)第六节。

| 编号 | 输出 | 含义 |
| --- | --- | --- |
| `E-IPL-01` | `1` | 描述符所在扇区读取失败（HDD） |
| `E-IPL-02` | `2` | 驱动器或介质不受支持：驱动器号不是硬盘、AH=48 返回短表、报告的扇区大小不是 512 / 4096 |
| `E-IPL-03` | `3` | 描述符头部或段序列非法：本区起始位置与槽不符、段头越过本扇区缓冲、段长小于段头、Stub 段长容不下起止位置、魔数不符 |
| `E-IPL-04` | `4` | Stub 段起止位置非法：起点不晚于描述符扇区、结束位置加一产生 32 位进位、起止倒置或扇区数为零 |
| `E-IPL-05` | `5` | 光盘候选驱动器探测未取得可读且魔数正确的描述符 |
| `E-IPL-06` | `6` | Stub 扇区数超过装载窗口上限 |
| `E-IPL-07` | `7` | 描述符通过后 Stub 读盘最终失败 |

序号在两个阶段一致：`E-STUB-40`..`E-STUB-51` 与 `E-CORE-40`..`E-CORE-51` 是同一批检查在各自阶段被查出时的编号。文本共用一份，改动须同时改两张表（`Packages/Baleen/Common/Src/ImageHeader.cpp`）。

## 五、维护规则

1. **首次发布之前不背兼容包袱**：编号直接改写、删除或重排，本文不留已废弃行。**首次发布之后编号只增不改**：含义变化时分配新编号，旧编号不再复用；删除的编号标记为已废弃，不回收。
2. 每条 `Baleen::Diagnostic` 常量都必须在本文登记；新增时同时改源码与本文。
3. 诊断行同时输出编号与文本；自动化按编号聚合，人按文本定位，两者都不作为唯一依据。
4. 存储层错误名（`Storage::ErrorMessage`）作为补充现场附在编号行末尾的括号里，不属于编号体系。
