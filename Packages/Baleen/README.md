# Baleen — 系统专用引导器

Baleen 是 LikesProgramOS 的自家引导器子项目，与系统本体 `LikesProgramOS` 平级。

它的职责只有一件事：**从不同硬件上找到指定 Ext4 文件系统的指定路径，把系统内核装载起来并完成交接。** 介质识别、卷定位、镜像装载、机器状态准备都在这一侧完成；内核不解析任何外部引导协议，见[内核启动与固件边界](../../Docs/Specs/内核启动与固件边界.md)。
