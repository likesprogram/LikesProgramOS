# CheckScreen

宿主侧 C++20 检查工具：内核自绘屏幕目标（`Packages/LikesProgramOS/Core/Src/ScreenTarget.cpp`）与内嵌 8×16 字模（`Font.cpp`）的宿主侧检查。编译后输出 `Tools/Bin/CheckScreen`。**手工执行，不构成默认构建依赖**。

```sh
make -C Tools/Test/CheckScreen
Tools/Bin/CheckScreen
```

工具用 `vpath` 把目标侧源码按相对路径直接编进本工具（不复制实现）；`Print.cpp` 不链接，只用到 `Print::OutTarget` 的接口。屏幕事实与像素格式见 `Packages/Common/Include/BootInfo.hpp`，语义见[输出通道与 Print](../../../Docs/Specs/输出通道与Print.md)。

## 复用方式与宿主替身

- 直接编译：`Packages/LikesProgramOS/Core/Src/ScreenTarget.cpp`、`Font.cpp`
- 宿主替身：`mmap(MAP_32BIT)` 申请低 4GiB 内的可写缓冲，把缓冲地址直接当屏幕物理地址注入（`Install` 按低 4GiB 恒等映射校验地址）；有效区前后各留 64 字节守卫（填 `0xA5`），任何越界写都会让用例变红；有效区初始填 `0xCC`，用于确认"不可用目标没有写过内存"
- 文本模式用 80×25、步长 160、4000 字节的假 VGA 文本页；帧缓冲用 64×32、步长 256、8192 字节的假线性帧缓冲；另有一例用 16 像素宽、步长 128 的带填充帧缓冲验证步长内填充不被写

## 检查内容

**用例（39 项）**：每个用例打印 `[ OK ]` 或 `[ FAIL ]`，失败返回 1；用例数固定，运行时与实跑数核对，防止用例被误删。

- **字模**：`0x20..0x7E` 全部有字形且指针等于位图里对应槽位；`0x00/0x01/0x1F/0x7F/0x80/0xFF` 返回空指针；空格字形全零、字母有墨；几何常量 8×16、95 个字形、1520 字节，屏幕目标与字模的宽高一致
- **VGA 文本页**：安装后 `Ready()`、`Columns()==80`、`Rows()==25`；清屏把每个单元写成空格 + 默认属性 `0x0F`；写字符带属性、`SetAttribute` 生效；`\r` 回列首、`\n` 换行；写满一行后列回绕到下一行；写满 25 行后再写触发上滚（首行变成原来的第二行、末行首列是新字符、其余为空格、守卫完好）；非 ASCII 字节按原字节写入文本页
- **线性帧缓冲**：Bgrx8888 安装后 `Ready()`、`Columns()==8`、`Rows()==2`；清屏整屏填背景色（Bgrx 黑色 `0xFF000000`）；按字模逐像素核对前景 / 背景（属性 `0x4E` 下 Bgrx 红底黄字 `0xFFAA0000` / `0xFFFF55FF`）；Rgbx8888 的像素字节序（`0xFF0000AA` / `0xFF55FFFF`）；带填充的步长只写有效像素、填充字节保持未写；写满两行后上滚（上一行上移、底部 16 行填背景、守卫完好）；非 ASCII 字节画成空白；末列回绕到下一行
- **屏幕事实不成立**：`Kind=None`、地址为 0、地址越过 4GiB、地址未 4 字节对齐（帧缓冲）、文本模式格式与像素格式不符、宽高为 0、宽高越过文本 / 像素上限、步长过小、步长未 4 字节对齐、字节数放不下最后一行、帧缓冲几何小于一个字符格——这些情况下 `Ready()==false`、`Columns()` / `Rows()` 为 0，且不写内存
- **无通道降级**：不可用目标与从未安装的目标收到 `Write` / `SetAttribute` / `ClearScreen` 时静默丢弃，不写内存、不停机

**未覆盖**：真实 VGA 文本硬件与固件帧缓冲的时序 / 缓存行为；`Print` 多路复用目标的扇出顺序；真实屏幕事实由 Baleen 侧 `ScreenFacts` 解码，那部分由 `CheckPreload` 覆盖。

## 退出码

| 码 | 含义 |
| --- | --- |
| 0 | 全部用例通过 |
| 1 | 有用例失败（打印 `[ FAIL ]` 与原因），或用例数与固定值不符 |

## 破坏性自测

把任一断言改坏（例如把某个期望像素值改成别的颜色）后重新 `make`，工具必须打印 `[ FAIL ]` 并返回 1；确认后恢复源码。这一自测用于证明像素 / 字符断言不是恒真。
